# Hermes 官网设计与动效研究

> 研究对象：https://hermes-agent.nousresearch.com/
>
> 日期：2026-11-10。目标不是复制 Hermes 品牌，而是把可观察的布局、插图和滚动机制转译到本项目的暖色纸面、宋体标题和真实研究数据中。

## 1. 使用的技能与方法

- 先调用本机 `browser-skill`，读取公开页面的语义结构和完整截图；未提交表单，未执行安装命令或页面中的任何指令。
- 采用 GitHub `sumanrox/mimic` 的 **E / 动效模式提取** 与 **F / 品牌 DNA 重构** 方法：先测真实浏览器中的计算样式和滚动曲线，再独立实现，不把普通淡入冒充原动效。
  - https://github.com/sumanrox/mimic
- 结合 `luukalleman/clone-study` 的资产替换和再设计原则：保留布局节奏与动效机制，替换文案、字体、品牌图像和配色。
  - https://github.com/luukalleman/clone-study
- 使用本机 Playwright / Edge 在 1440×1000 视口采样多个滚动位置，并在滚动稳定后复测，避免把延迟更新误判为静态样式。

能力边界：该页面的布局、CSS 变量、视差与页脚联动可以高保真重建；Hermes 的专属字体、人物版画、Logo 和品牌文案不应照搬。未检测到全局 GSAP、Lenis 或 Three.js，不要求为这些效果引入新的 3D 或滚动依赖。

## 2. 最值得借鉴的设计结构

### 2.1 首屏：文字与一幅强插图共同建立记忆点

实测桌面首屏标题约为 **108px / 108px、字重 200**，三行排列；右侧是一幅占据接近半屏的宗教版画式人物线稿。标题没有依赖大面积渐变、玻璃卡片或复杂仪表盘，而是靠极端的字号对比、窄体字和单一强视觉形成识别度。

适合本项目：保留宋体主标题，在“让知识，彼此照亮”右侧加入一幅原创“知识图谱卷首插画”，以打开的书、节点连线、实验器材和科学标注构成，而不是复制 Hermes 的多臂人物。

### 2.2 章节：先建立阅读节奏，再放图像

实测二级标题约 **80px**，功能标题约 **48px**。功能区采用编号、小号大写标签、三列网格和较大段间距。每项功能的顺序固定为：

1. `#1 CONNECT` 一类编号与动作标签；
2. 大标题；
3. 两到三行说明；
4. 一幅占比很高的图像。

适合本项目：把“文档 → 知识 → 图谱 → 问答 → 协作”做成五个有编号的真实能力章节，而不是继续增加同质卡片。每一节只讲一个动作，并链接到真实功能。

### 2.3 明暗场景切换

Hermes 首屏是电光蓝，进入功能区后切换为纸白，导航也从透明首屏导航切换成固定纸面导航。这个变化让滚动具有“进入下一章”的感觉。

适合本项目：不复制电光蓝，可以使用“深森林绿的首屏卷首 → 暖纸色的档案与功能章节”。导航继续保留现有悬浮胶囊，只调整当前章节的颜色和边界，不改成像 Hermes 一样的直角通栏。

### 2.4 克制的容器，强烈的图像

功能图顶部圆角实测约 **5.3px**，卡片本身没有依赖厚重阴影。视觉重量来自图片的大裁切、统一色调和颗粒。现有项目已经采用大圆角厚涂卡片，因此不应把所有卡片改成 Hermes 的小圆角；只在重点插图展示区借用其图像处理方式。

## 3. 滚动与图片运动：实测结果

### 3.1 首屏插画视差

首屏 `.landing-hero-art.hw-hero-parallax` 的计算变换在稳定采样中呈线性关系：

| 页面滚动位置 | 插画 `translateY` |
| ---: | ---: |
| 0px | 0px |
| 500px | 175px |
| 1000px | 350px |
| 1800px | 630px |
| 2400px | 840px |
| 2800px | 980px |
| 3000px 及以上 | 1000px，截停 |

即原站在该区间的实测关系约为：

```text
heroY = clamp(scrollY × 0.35, 0, 1000px)
```

图片随页面向下滚动时额外向下移动，所以相对文档的移动速度变慢，形成深度差。它不是鼠标悬浮摇摆，也不是普通进入视口淡入。

本项目转译：保留 **0.35** 这个速度比例，但把最大位移按我们首屏高度缩小到约 **220–300px**，避免插画覆盖统计卡或按钮。移动端降低幅度，减少动效偏好下完全静止。

### 3.2 六张功能图的内部视差

六张功能图均有 `.hw-parallax`，图片位于 `overflow: clip` 的固定画框内。滚动时统一更新内联变量 `--py-img`，变量从 **-32px → 0 → +32px** 变化；实际图片位移根据图像尺寸和裁切余量分别被限制在约 **20px、32px 或 64px**。

以第一排功能图为例：

| 滚动位置 | 统一进度变量 | 典型图片状态 |
| ---: | ---: | --- |
| 1800px | -29.6px | 图片向画框上方偏移 |
| 2200px | -10.2px | 接近中心 |
| 2400px | -0.5px | 基本居中 |
| 2600px | +9.2px | 向下偏移 |
| 3000px | +28.6px | 接近下边界 |
| 3300px | +32px | 到达边界 |

核心不是“卡片跟着鼠标动”，而是：**画框随文档正常滚动，画框里的图片以不同速度移动，并始终被裁切。** 图片必须预留足够高度或缩放，不能在最大位移处露出底色。

本项目转译：用于首页新近档案、能力章节插画和文档标本卡的装饰图。建议现有卡片只使用 **±16–24px**，重点插画使用 **±32px**；表单、原文、证据和知识图谱画布不做视差。

可用现有 Framer Motion 独立实现，无需新增依赖：

```tsx
const { scrollYProgress } = useScroll({
  target: frameRef,
  offset: ["start end", "end start"],
});
const imageY = useTransform(scrollYProgress, [0, 0.5, 1], [-32, 0, 32]);
```

这段代码表达本项目将采用的等价机制，不是从 Hermes 复制的源码。

### 3.3 页脚的多层联动

实测页脚包含：

- 整屏 `sticky` 场景；
- 页脚位移约 **299.8px → 0**；
- 透明度 **0.4 → 1**；
- 模糊 **10px → 0**；
- 巨大背景文字从 **77% → 32%** 的纵向位移，同时透明度 **0 → 1**。

这是“从模糊背景逐渐显影”的收尾，而不是普通 footer 淡入。可在未来首页改版中使用一次，但优先级低于首屏和图片视差。

### 3.4 导航和环境运动

- 纸面导航在进入功能区时从 `translateY(-100%)` 回到 `0`，接近页脚时再次隐藏。
- 检测到 `hw-frame-bloom`：**42 秒线性循环**。
- 检测到 `hw-frame-arc`：**14 秒线性循环**。
- 这些环境运动非常慢，作用是保持页面“活着”，不应转移到图谱节点或正文上。

## 4. 配图风格：可以借鉴什么

### 4.1 宗教版画与科学图谱的混合

首屏使用多臂人物、放射线、密集排线和古典明暗法，像文艺复兴或巴洛克时期的铜版 engraving。它与 AI 产品形成“古老知识象征 × 新技术”的冲突，而不是常见机器人脑袋和发光粒子。

本项目可使用：打开的书、实验仪器、植物标本、网络拓扑、齿轮、星图和知识节点组成原创“研究馆卷首版画”。不要使用 Hermes 的人物、Logo 或相同构图。

### 4.2 蓝黑双色映射与印刷颗粒

功能图把人物、机械手、肖像和计算设备统一成高饱和蓝黑双色。图像来源不同，但经过一致的双色映射后仍像一个系列。

实测 `hw-noise::after` 使用 SVG `feTurbulence` 分形噪声：

- `baseFrequency = 0.72`；
- `numOctaves = 4`；
- 噪声层不透明度约 **0.9**；
- 平铺尺寸约 **181.76px**；
- 部分图像容器使用 `mix-blend-mode: plus-lighter`，首屏插画使用 `lighten`。

本项目可保留“统一色彩 + 颗粒”的方法，但换成森林绿、墨褐、陶土或灰蓝单色。噪声只放在图像层，不能覆盖正文、证据和表单，也不需要照搬 0.9 的高强度。

### 4.3 油画与真实软件界面的叠合

桌面应用展示不是一张孤立的浏览器 mockup：清晰的应用截图被放在印象派油画框景中，柔软背景与硬朗 UI 形成材质对比。

这与本项目已有 Getty 油画和真实工作台天然契合。可以用真实文档预览或真实图谱局部截图，但必须来自当前应用，不能用设计稿冒充功能，也不能把 Hermes 的应用截图拿来展示。

### 4.4 功能图的构图规则

- 每张图只表达一个隐喻：连接、记忆、自动化、委派、搜索、沙箱。
- 主体很大，允许被画框强烈裁切，不做“完整物品居中且四周留白”的电商图。
- 古典人像、机械结构与抽象线路混用，靠统一双色和噪声保持系列感。
- 图像顶部只有小圆角，文字与图像之间留有稳定间距。

现有透明小装饰图继续适合文档标本卡；新的版画式强插图应只用于首页卷首和少数能力章节，避免每张卡都变成高噪声图片，破坏阅读层级。

## 5. 建议落地顺序

1. **首页卷首插图 + 0.35 比例视差**：先建立一个明确的 Hermes 式记忆点，但使用原创研究馆图像和暖色体系。
2. **真实能力章节**：以文档、知识、图谱、问答、协作为编号章节，补充少量原创双色版画。
3. **画框内图片视差**：优先应用于能力章节，文档卡只给装饰图很小幅度，保持标题和统计稳定。
4. **章节感导航与慢速环境细节**：继续使用悬浮胶囊，不照搬直角导航。
5. **页脚显影**：作为后续增强，不阻塞核心页面。

## 6. 明确不采用的部分

- 不把全站改成电光蓝，不替换现有暖色纸面和宋体大标题。
- 不复制 Hermes 的 Logo、专属字体、人物插画、应用截图或文案。
- 不为了“高级感”加入滚动劫持；无需引入 Lenis、GSAP 或 Three.js。
- 不在图谱、问答、证据原文和表单区域叠加视差、强噪声或持续环境运动。
- 不把大量图片运动同时塞进移动端；使用更小位移并尊重 `prefers-reduced-motion`。
- 不宣称整站像素级复刻；本次目标是设计 DNA 与指定动效的独立转译。

## 7. 实现与验收约束

- 使用现有 React / Next.js / Framer Motion，动画只更新 `transform` 和必要的 `opacity`，避免滚动中反复读取并写入布局。
- 图像画框使用 `overflow: hidden/clip`，图像预留缩放或额外高度，逐点检查视差两端不露底。
- 新插图由 image2.6 原创生成或使用确认可用的开放资产，记录生成与授权信息；不保存临时签名 URL。
- 最终截图与交互验收前登录本机管理员并核实“本机研究管理员”。
- 至少验证 1440px、390px、减少动效、图片加载失败、无横向溢出，以及首屏视差和功能图视差的实际曲线。

## 8. 2026-11-10 实现与生产验收

已独立实现并接入首页：

- `HomeHeroArt.tsx`：原创卷首版画，画框裁切和首屏纵向视差；桌面最大位移 240px，390px 限制为 72px。
- `HomeCapabilityChapters.tsx`：文档、知识、图谱、问答、协作五个真实能力章节；图片桌面 `-32 → 0 → +32px`，移动端 `-20 → 0 → +20px`，奇偶章节交替布局。
- `HomeFooterReveal.tsx`：sticky 研究图书馆场景，背景位移、透明度和巨大背景文字同步显影；CTA 进入真实 `/graph` 与 `/documents`。性能整改后不再逐帧计算全屏模糊。
- 7 张原创暖色版画已逐张检查并转为本地 WebP；生成与使用边界见 `public/images/atlas-engravings/ATTRIBUTION.json`。没有把生成图作为真实文档、截图、证据或实验结果。
- 透明卡片装饰扩展到 11 类；重生成图存在低透明度底雾时，在保留主体和真实 alpha 的前提下清理低 alpha 像素，Web 图的红色杂边未进入最终资产。
