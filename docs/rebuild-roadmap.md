## 当前完成边界

当前首页仍使用明确标注的演示数据；知识星图默认读取真实已发布数据，并提供明确标注的“交互演示”开关。文档中心已接通登录上传、SQLite 持久任务、真实 PDF/DOCX 解析、失败重试和一致性删除，也提供按需知识抽取、证据审阅和人工发布界面。研究助手使用登录后的全文检索和 Qwen 证据回答，已接入 SSE、取消、重试及账号隔离的会话历史，但不是向量 RAG；真实 Qwen 在线抽取与真实 Qwen SSE 仍需分别进行经确认的单次验收。账户注册、审核、会话、公开/私有/团队文档授权和团队管理已接通。旧版 `/api/v1/*` 代理已停用。本清单中的勾选项只表示已验证的实现，不代表云端已部署。

本轮上传、知识与会话界面已在隔离数据库副本中通过本机 Edge 验收：匿名 50 份公开文档、真实上传后 51 份、团队创建与邀请、费用确认前禁止抽取、真实/演示图谱切换、SSE 完整回答、无证据 JSON、取消后的 incomplete、保留旧记录的重试、会话重命名与刷新恢复，以及 390px 无水平溢出，控制台无错误。验收未调用在线知识抽取模型；会话 SSE 使用模拟上游，未产生外部模型费用，也未修改正式语料库。四个并行模块全部返回并完成主代理审查后，最终 TypeScript 检查通过，13 个 Vitest 文件共 81 项测试通过，14 项 Python 测试通过，Next.js webpack 生产构建成功。此前 Obsidian 与账户增量也已通过关键交互回归。详细边界见 `docs/auth-and-access.md`、`docs/ingestion-pipeline.md`、`docs/knowledge-extraction.md` 与 `docs/conversation-rag.md`。
