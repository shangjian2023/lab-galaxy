> 2026-11-19 拟定,基于当前工作区代码与 `data/lab-galaxy.db` 真实数据勘探。

## 一、成片规格

| 项 | 值 |
|---|---|
| 分辨率 / 帧率 | 1920 × 1080 @ 30fps |

## 二、叙事主线

采用平台首页自带的五章叙事(COLLECT → DISTILL → CONNECT → QUESTION → COLLABORATE),演示即"把这五章演真":

**一页档案 → 解析成块 → 凝结成知识 → 连成星图 → 回到原文追问**

**三大主打功能以编号名牌凸显,贯穿全片主线**:
- **主打 01 · 知识星图**(S2):515 实体 / 492 关系的 Obsidian 式交互图谱
- **主打 02 · 文档 → 知识流水线**(S3+S4):上传 PDF → 解析分块 → 抽取发布,闭环入图
- **主打 03 · 证据问答**(S5):@节点提问,流式回答,每条结论回到原文

## 六、BGM 方案(草稿版即含)

**选曲气质**:贴合"档案馆 / 铜版画 / 知识馆"的静谧调性——新古典钢琴或钢琴+弦乐,慢板(≤ 90 BPM),无人声,动态平缓不抢交互字幕;结尾可随 ATLAS 显影自然收束。

**混音规格**:BGM 音量约为满幅的 20–25%,头 2s 淡入、尾 3s 淡出,循环拼接处交叉淡化,时长对齐视频;草稿无人声故不做 ducking(日后加配音则降至 ~15% 并加侧链避让)。

```bash
# 成片合成示意(BGM 循环 + 淡入淡出,时长对齐视频)
ffmpeg -i video.mp4 -stream_loop -1 -i bgm.mp3 \
  -filter_complex "[1:a]volume=0.22,afade=t=in:st=0:d=2,afade=t=out:st=<dur-3>:d=3[a]" \
  -map 0:v -map "[a]" -c:v copy -c:a aac -shortest out.mp4
```

**曲源三个选项**:

| 选项 | 说明 | 费用 | 备注 |
|---|---|---|---|
| A. CC0 / 无版权曲库 | Pixabay Music、Free Music Archive、Incompetech(CC-BY,片尾注明作者即可)等,选静谧钢琴曲 | 免费 | 曲目质感专业、现成;我来挑 2–3 支供你试听定夺 |
| B. AI 生成 | magpie 里 minimax `batch_text_to_music`,按气质生成定制曲(提示词如"calm neoclassical piano, museum archive atmosphere, slow") | 走 magpie 套餐额度 | 可定制但质量有随机性,需生成几版挑选 |
| C. 自备 | 你提供 mp3/flac 文件 | — | 最合口味,直接用 |

### v5 字幕重建(同日晚)
原烧录字幕每条仅停留 ~3s,旁白一句 5-10s,起点对齐仍会句中错位。终案:后期重建字幕层——drawbox 全程遮盖原字幕带(x430 y992 w1060 h68,0x1E1913 全不透明),drawtext(simsun 24px #F2E9DA)按旁白分句 34 条逐句生成,与配音同源同轴,天然 100% 对齐;并补显"通用AI有幻觉"等未上屏句。生成器 scripts/demo/gen-v6-filter.mjs,滤镜 data/demo/tts/v6-filter.txt。注意:该 ffmpeg 构建 drawtext 引号内不保护半角冒号,文案冒号一律全角"："。
