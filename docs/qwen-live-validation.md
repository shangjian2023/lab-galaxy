## 4. 50 份预置报告批处理与内容审阅

在已授权的现有 50 份公开报告范围内，使用服务端 `qwen3.7-plus` 分批执行知识抽取。批处理保留 `confirmCost: true`、严格 JSON/枚举/关系端点校验、证据 chunk 校验和人工发布边界；网络错误、超时、HTTP 429、无效 JSON 与内容质量不合格结果均未被当作成功发布。

处理过程包括首轮抽取、失败重试、单 chunk 定向重抽和独立证据内容审阅。审阅不仅检查结构，还核对摘要与关系是否由登记的同一 chunk 支持；跨 chunk 数值错配、无条件泛化、标准归属错误及作用对象替换均被拒绝。最终只发布审阅通过的草稿。
